Review notes

This revision preserves the five-screen structure. Grounding has five manual sensory steps and an intended 70-second path; this static preview shows Touch only, without real interactions. Original Part 3.1 STOP gallery.

Each frame is 390 × 844 CSS pixels at full size. The grid wraps; on narrow browsers the frame width adapts without shrinking its text or touch targets. Blue outlines appear on keyboard focus. Buttons intentionally have no action.

The daily popup adds an interruption even with Skip. Persistent safety access uses header space. The breathing graphic is static; the final application still needs a reduced-motion alternative, modal focus management, timing and navigation verification. This gallery does not demonstrate those behaviors, crisis resources, later AI responses, or saved history.
