## Review boundaries

Codex assisted implementation/debugging/testing/documentation; ChatGPT-assisted planning/instructions reflect the developer's workflow. Neither tool supplies new clinical research. Design attribution remains the instructor-provided R1–R4/D1–D6 study summary. Exact development model versions not captured by the project are not reconstructed from memory.

The evidence log intentionally links selected public-safe files instead of reproducing whole chats, local environment files, private previous-project contents or unredacted provider payloads. No new provider requests were required for this log. It records failed/revised approaches and unresolved checks rather than presenting every generated result as correct.
